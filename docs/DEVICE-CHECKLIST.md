# 真机深链验收清单

模拟器里没有第三方 App，`canOpenURL` 一律返回 false，所以深链只能在真机上验证。
这一页是给人手动过的，不追求全自动。全部过一遍大约 20 分钟。

## 怎么测

1. 把 App 装到 iPhone 上，确认目标 App 也装了。
2. 首页输入 `用 <应用名> 搜索 测试`，回车。
3. 看三件事：
   - 有没有打开对的 App
   - **关键词有没有带进去**
   - 打开后是不是直接落在搜索结果页
4. 在下面的表里打勾。失败的在「处理」列写一句原因。

判定用三档：

| 符号 | 含义 | 怎么处理 |
|---|---|---|
| ✅ | 直达搜索页，关键词正确 | 不动 |
| ⚠️ | App 打开了，但停在首页 / 关键词丢了 | 改成 `copyOnOpen`（复制关键词 + 打开 App） |
| ❌ | 根本没打开，或整条链接无效 | 改成网页兜底，或删掉这条 |

## 改法

两条路，选一条：

**A. 临时改（不用重新编译）**
App 里 → 右上角设置 → 找到那个应用 → 长按 → 改跳转地址。
改完立刻生效，会同步刷新小组件。

**B. 永久改（写进代码）**
改 `JumpSearch/Destinations.swift` 里对应的 `url` 或加 `copyOnOpen: true`，重新编译。
缺 `{q}` 的模板会在运行时报错并改成「复制 + 打开」，不会静默失败。

## 额外要看的

深链之外，这几条也建议在真机上顺手确认：

- [ ] 第一次打开有引导，讲清楚 `XH = 小红书`
- [ ] 应用槽输入 `XH`，后面出现灰字「小红书」，回车确认
- [ ] 输入法组词过程中，灰字预览跟着变
- [ ] 长按关键词框能选词、能移动光标（不应该触发说话）
- [ ] 想法卡片点正文能就地编辑，点「去搜」能升起面板
- [ ] 面板里的「常去」胶囊点一下直接搜
- [ ] 记录左滑超过 72pt 删除，不到阈值回弹
- [ ] 没装对应 App 时弹窗，能用网页兜底
- [ ] 主屏小组件点击后唤起 App 并聚焦
- [ ] 锁屏小组件先要求解锁再进 App
- [ ] 打开「减弱动态效果」后墨晕停住
- [ ] 系统切深色模式，主 App 和小组件同步
- [ ] VoiceOver 下按钮都有可读标签
