# v3 结构方案

v2.2 是在现有结构上把细节做对；这一版问的是**结构本身**。

一句话：**这个 App 的界面只需要回答一个问题——"我这一下按下去，会发生什么"。** 现在配角太多，都在抢戏。

---

## 1. 删掉三样

### 1.1 呼吸圆

`ContentView.swift:75` `BreathingSubmitButton`，3.4s `repeatForever`。

它不传递任何信息，只是让静止的界面一直在动。用户盯着它等的时候，反而觉得 App 慢。效率工具的等待感，一半是自己动出来的。

**改成**：静止的环，有关键词时收紧成实心圆。删掉 `repeatForever`。

### 1.2 底部常驻 tab

`ContentView.swift:306` 和 `:758`，`Screen` 枚举（`:244`）现在是三个平级页面。

搜索是根，想法和记录是收件箱。两个 tab 占了 50pt 的黄金位置，还把搜索降级成三选一。

**改成**：`Screen` 只留 `search` / `inbox` 两个值，收件箱在右上角一个书签入口，进去后用分段控件切「想法 / 记录」。

**代价**：想法的发现性下降。这是这一版唯一明确的损失，如果想法是核心功能，就别删 tab。

### 1.3 顶部 wordmark

用户已经打开了这个 App，不需要再被告知一次。品牌靠字体和留白建立。

**改成**：顶部只留右侧两个入口（收件箱、设置）。

## 2. 加两样

### 2.1 最近用过的三个应用

"用 ___ 搜索 ___" 要求用户记住 24 个应用里的别名，这是把系统的记忆负担转嫁给用户。

**行为**：应用槽为空时，句子下面浮一行「最近 小红书 豆瓣 闲鱼」，取历史记录里前 3 个不重复的应用。点一下填进应用槽并聚焦关键词；一旦开始打字，整行消失。

**实现**：`Store` 里加一个计算属性，从 history 去重取前 3；不要新存字段。

### 2.2 「存为想法」次按钮

见第 4 节。

## 3. 收件箱

一个页面，两种内容，长得不一样：

| | 想法 | 记录 |
| --- | --- | --- |
| 形态 | 卡片，圆角 16，底色 `Theme.card` | 一行一条，0.5pt 细线分隔 |
| 内容 | 正文（宋体 15.5，行高 1.75） | 关键词 + 右侧应用名 |
| 交互 | **点一下就地编辑**，回车收起 | 点开换应用面板，左滑删除 |
| 理由 | 想法是"我要留着的东西"，会反复改 | 记录是"我做过的事"，只能重搜 |

就地编辑用卡片内嵌 `TextEditor` 或 `TextField(axis: .vertical)`，不要跳面板——跳面板意味着"编辑"是另一件事，而它应该是同一件事。

删除入口：桌面 / 触屏都要能点到，不要只留手势。

---

## 4. 回车恒等于搜索

这是整份方案里最重要的一条。

现在的规则是"超过阈值回车存想法"，用户事前不知道。v2.2 的方案是把它**可见化**（加胶囊、换图标、换 returnKey）。可见化是止血——用户还是得先读一行字，才知道回车会干什么。

**改成**：

| 条件 | 回车 | 「存为想法」按钮 |
| --- | --- | --- |
| 任意长度 | **搜索** | 不超过阈值时不显示 |
| 超过阈值 | 搜索 | 右下角出现，雾绿小字 |
| 长按主按钮 | — | 强制存为想法 |

- 阈值（默认 20 字）从"回车判定"降级为"按钮何时出现"。
- 输入法组字期间不重算按钮显隐。
- 面板里的关键词永远搜索。

**用户永远不用想"这次回车会怎样"**——这是这个 App 最该省掉的一次思考。

## 5. 动效

四档，硬上限 360ms：

| 用途 | 时长 | 曲线 |
| --- | --- | --- |
| 按压 | 90ms | `timingCurve(0.16, 1, 0.3, 1)` |
| 图标 / 下划线 / 状态切换 | 180ms | 同上 |
| 页面进出 | 220ms | 同上 |
| 面板升起 | 340ms | `timingCurve(0.2, 1.08, 0.3, 1)` |

规则：

1. **只留一个主角动效**——存想法时飞向收件箱入口的绿点（320ms，中途抬 22pt）。其他全部在 180ms 内解决。
2. **页面之间交叉淡入，不要左右滑**。两个页面是平级的，滑动会暗示层级，用户会期待能滑回去。
3. 只动 `transform` / `opacity`。
4. `accessibilityReduceMotion` 为真时全部塌到 0。

`PressableStyle` 的 0.28s 改成 90ms + `scale(0.96)`。按下去应该是"咔"的一下，不是陷进棉花。

## 6. 触觉

比动画先到手指，比任何缓动都直接。

| 时机 | 反馈 |
| --- | --- |
| 触发搜索 | `UIImpactFeedbackGenerator(style: .light)` |
| 存为想法 | `UINotificationFeedbackGenerator().notificationOccurred(.success)` |
| 切换分段 / 模式 | `UISelectionFeedbackGenerator()` |

## 8. 实施顺序

1. `refactor: Screen 只留 search / inbox，收件箱改分段`（结构先立住）
2. `feat: 关键词框自增高`（v2.2 §2，v3 依赖）
3. `feat: 回车恒搜索 + 存为想法次按钮`
4. `feat: 想法改卡片，支持就地编辑`
5. `feat: 最近三个应用`
6. `style: 动效与触觉统一`（含删呼吸圆）

第 1 步做完就能跑，后面每一步都是独立可回滚的。
